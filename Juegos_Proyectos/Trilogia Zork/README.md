# Trilogía Zork (Tintero Motor de Aventuras)

Esta carpeta contiene la adaptación no oficial de la trilogía Zork para el Tintero Motor de Aventuras.

- Autoría original: Infocom (Zork I–III)
- Adaptación al español y al Motor de Aventuras: Atoky
- Formato: archivos .ma compatibles con el Motor de Aventuras de Tintero

## Archivos

- zork1.ma — Zork I: El Gran Imperio Subterráneo
- zork2.ma — Zork II: El Mago de Frobozz
- zork3.ma — Zork III: El Maestro del Calabozo

## Notas

Adaptación no oficial para el Motor de Aventuras hecha por Atoky.
